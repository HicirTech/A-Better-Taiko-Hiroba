# How these tests treat Hiroba pages

Parser tests assert against **hand-written excerpts**: the smallest HTML that states the claim
under test, holding no real account data.

The real captured pages this project was mapped from are not in the repository and must not enter
it — they carry a real taiko number, nickname and session tokens, and anything committed here lands
in public history permanently. They are kept privately as reference material; writing an excerpt
starts by reading them there.

An excerpt is a claim about the real page's shape. When an excerpt and the real page disagree, the
[wiki](https://github.com/HicirTech/A-Better-Taiko-Hiroba/wiki) — the authority on Hiroba — settles
it, and the correction lands in the same piece of work.

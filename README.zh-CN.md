# A Better Taiko Hiroba

[English](README.md)

一套面向鼓众广场（donderhiroba.jp，日服）的客户端工具。它可以在桌面端、安卓端以及之后的命令行中查看并修改你自己的太鼓游玩数据——成绩、资料、小咚、收藏曲目、各项设定等。工具运行在你的设备上，并直接与广场通信；你的数据不会经过我们的任何服务器。

## 下载

在 [Releases 页面](https://github.com/HicirTech/A-Better-Taiko-Hiroba/releases/latest)下载最新版本：Windows 有安装包和免安装的 zip，安卓是 APK。有新版本时，App 会提醒你。

## 它能做什么

* [x] 用万代南梦宫 ID 登录，并保持登录状态
* [ ] 查看所有曲目的全部难度：皇冠、评价、分数、打击数、游玩选项
* [x] 查看自己的资料、小咚、称号、段位、成绩统计和收藏曲目
* [ ] 查看近期游玩记录
* [x] 更换称号
* [ ] 按部件拼出称号
* [x] 修改昵称
* [x] 更换小咚的服装与配色
* [x] 换装保存前可以预览，也能换回穿过的装束
* [ ] 修改游戏设定
* [x] 修改最爱歌曲和收藏夹
* [x] 在本机保存多套收藏，一次保存就能整个换掉收藏夹
* [x] 按分类、难度、星级以及日文、英文、中文歌名的一部分找歌，条件可以叠加，并显示作者和各难度的星级
* [x] 在首页查歌：看 BPM、各难度的星级和最大连段，以及谱面图
* [ ] 断网时也能浏览本地数据库
* [ ] 同时管理多个账号
* [ ] 增量同步，断点可续传
* [ ] 以命令行方式运行
* [x] 作为桌面端应用运行（Windows）
* [x] 作为安卓端应用运行
* [ ] 作为 iOS 端应用运行——后期
* [ ] 作为 Web 端应用运行——后期
* [ ] 通过脚本驱动同一个核心，提供可编程 API
* [x] 界面支持英文、日文、简体中文和繁体中文
* [x] 有新版本时提醒你
* [ ] 将成绩上传到菌菌

## 几句实话

**非官方。** 本项目与万代南梦宫娱乐没有任何关系，也未获得其授权或背书。太鼓の達人、ドンだー広場均为其所属。

**默认客气。** 广场是别人的服务。抓取过程刻意放慢，并且只获取发生变化的部分；当对方限流时，会自动退回并等待。
“多抓一点”必须由你明确提出，不会自动发生。

**歌曲资料来自社区。** 作者、星级和其他语言的歌名来自 [taiko.wiki](https://taiko.wiki/) 和中文的 [太鼓之達人維基](https://taiko.fandom.com/zh/)（其歌名按 CC BY-SA 使用）。App 只读取它们公开的列表，不会向它们发送你的任何数据。

**账号是你的，决定也由你承担。** 这套工具会以你的身份登录，并操作你真实的太鼓资料；账号始终是你的，后果也同样由你承担。

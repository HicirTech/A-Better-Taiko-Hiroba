# A Better Taiko Hiroba - 一个更好的鼓众广场

[English](README.md)

一套面向鼓众广场（日服）的客户端工具。目前支持桌面端、安卓端以及之后的命令行查看自己的太鼓游玩成绩、修改资料、显示小咚、切换收藏曲目、管理广场上的各项设定等。本工具设计上是完全在设备上运行，并直接与广场通信: 任何你的鼓众数据都不经过我们的任何服务器(因为我根本就没搭服务器)

## 下载

在 [Releases 页面](https://github.com/HicirTech/A-Better-Taiko-Hiroba/releases/latest)下载最新版本：Windows 有安装包和免安装的 zip，安卓是 APK。有新版本时，App 会提醒你。

## 它能做什么

* [x] 用万代南梦宫 ID 登录，并保持登录状态
* [ ] 查看所有曲目的全部难度：皇冠、评价、分数、打击数、游玩选项
* [x] 查看自己的资料、小咚、称号、段位、成绩统计和收藏曲目
* [ ] 查看近期游玩记录
* [x] 更换称号
* [ ] 按部件拼出称号
* [x] 修改昵称
* [x] 更换小咚的服装与配色
* [x] 换装保存前可以预览，也能换回穿过的装束
* [ ] 修改游戏设定
* [x] 修改最爱歌曲和收藏夹
* [x] 在本机保存多套收藏，一次保存就能整个换掉收藏夹
* [x] 按分类、难度、星级以及日文、英文、中文歌名的一部分找歌，条件可以叠加，并显示作者和各难度的星级
* [x] 在首页查歌，或在收藏页点开歌曲：看 BPM、各难度的星级和最大连段，以及可以全屏放大的谱面图
* [ ] 断网时也能浏览本地数据库
* [ ] 同时管理多个账号
* [ ] 增量同步，断点可续传
* [ ] 以命令行方式运行
* [x] 作为桌面端应用运行（Windows）
* [x] 作为安卓端应用运行
* [ ] 作为 iOS 端应用运行——后期
* [ ] 作为 Web 端应用运行——后期
* [ ] 通过脚本驱动同一个核心，提供可编程 API
* [x] 界面支持英文、日文、简体中文和繁体中文
* [x] 有新版本时提醒你
* [ ] 将成绩上传到菌菌

## 恕我直言

本项目是**非官方**的鼓众客户端, 本项目与万代南梦宫娱乐没有任何关系，也未获得其授权或背书。太鼓の達人、ドンだー広場均为南梦宫所属

鼓众广场是南梦宫的服务, 所以在数据抓取过程中会刻意放慢速度以防止被南梦宫ban

**歌曲资料来自社区。** 作者、星级、BPM 和其他语言的歌名来自 [taiko.wiki](https://taiko.wiki/) 和中文的 [太鼓之達人維基](https://taiko.fandom.com/zh/)（其歌名按 CC BY-SA 使用）。谱面图是 taiko.wiki 链接的图片，存放在它自己的服务器、[太鼓の達人 譜面とかWiki](https://wikiwiki.jp/taiko-fumen/) 和 Imgur 上。App 只读取它们公开的内容，不会向它们发送你的任何数据。

这套工具会以你的身份登录，并操作你真实的太鼓资料: 数据无价, 谨慎操作

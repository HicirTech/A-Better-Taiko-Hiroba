# A Better Taiko Hiroba

[English](README.md)

一套面向鼓众广场（donderhiroba.jp，日服）的客户端工具。它可以在桌面端、安卓端或命令行中查看并修改你自己的太鼓游玩数据——成绩、资料、小咚、各项设定等。工具运行在你的设备上，并直接与广场通信；你的数据不会经过我们的任何服务器。

## 它将会做什么

* [ ] 用万代南梦宫 ID 登录，并保持登录状态
* [ ] 查看所有曲目的全部难度：皇冠、评价、分数、打击数、游玩选项
* [ ] 查看自己的资料、小咚、称号、段位
* [ ] 查看近期游玩记录
* [ ] 按部件编辑称号
* [ ] 修改玩家名字
* [ ] 更换小咚的服装与配色
* [ ] 修改游戏设定
* [ ] 修改收藏曲目
* [ ] 每次改动前提供预览，改动后支持还原
* [ ] 断网时也能浏览本地数据库
* [ ] 同时管理多个账号
* [ ] 增量同步，断点可续传
* [ ] 以命令行方式运行
* [ ] 作为桌面端应用运行
* [ ] 作为安卓端应用运行
* [ ] 作为 iOS 端应用运行——后期
* [ ] 作为 Web 端应用运行——后期
* [ ] 通过脚本驱动同一个核心，提供可编程 API
* [ ] 支持英文、日文、中文界面
* [ ] 将成绩上传到菌菌

## 几句实话

**非官方。** 本项目与万代南梦宫娱乐没有任何关系，也未获得其授权或背书。太鼓の達人、ドンだー広場均为其所属。

**默认客气。** 广场是别人的服务。抓取过程刻意放慢，并且只获取发生变化的部分；当对方限流时，会自动退回并等待。
“多抓一点”必须由你明确提出，不会自动发生。

**账号是你的，决定也由你承担。** 这套工具会以你的身份登录，并操作你真实的太鼓资料。每次改动前都会先说明将要做什么，以及之后如何还原；但账号始终是你的，后果也同样由你承担。

# A Better Taiko Hiroba

[English](README.md)

一套鼓众广场（donderhiroba.jp，日服）的客户端工具：在桌面端、安卓端或命令行里查看和修改自己的太鼓
游玩数据——成绩、资料、小咚、各项设定，不用再在原站上绕来绕去。它跑在你自己的设备上，直接和广场
打交道，你的数据不经过我们的任何服务器。

## 它将会做什么

- [ ] 用万代南梦宫 ID 登录，并且一直保持登录
- [ ] 看所有曲目的所有难度：皇冠、评价、分数、打击数、游玩选项
- [ ] 看自己的资料、小咚、称号、段位
- [ ] 看近期游玩记录
- [ ] 改称号，一个部件一个部件地改
- [ ] 改玩家名字
- [ ] 改小咚的服装和配色
- [ ] 改游戏设定
- [ ] 改收藏曲目
- [ ] 每次改动前能预览，改完能还原
- [ ] 断网也能翻本地数据库
- [ ] 同时放得下好几个账号
- [ ] 增量同步，断了能接着跑
- [ ] 在命令行里跑
- [ ] 做成桌面端
- [ ] 做成安卓端
- [ ] 做成 iOS 端——后期
- [ ] 做成 Web 端——后期
- [ ] 用脚本驱动同一个核心，走一套可编程 API
- [ ] 界面支持英文、日文、中文
- [ ] 把成绩传到菌菌

## 几句实话

**非官方。** 本项目和万代南梦宫娱乐没有任何关系，也未获其背书。太鼓の達人、ドンだー広場都是人家的。

**默认客气。** 广场是别人的服务器。抓取有意放慢，而且只抓变过的部分；对方一限流就退回去等。
「多抓一点」得你开口，不会自己发生。

**账号是你的，主意也得你拿。** 这套工具以你的身份登录，动的是你真实的太鼓资料。每次改动之前它会
告诉你要做什么、之后怎么改回去——但账号终归是你的，后果也一样。
